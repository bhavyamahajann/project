# Project Screenshots

Add your project screenshots here!

## Instructions:

1. Take a **tall, full-page screenshot** of each project website (mobile view works best)
2. Save the images in this folder with descriptive names like:
   - `client-one.jpg`
   - `ecommerce-project.png`
   - `restaurant-website.jpg`

3. Update the `PROJECTS` array in `src/components/ProjectsShowcase.jsx`:

```javascript
const PROJECTS = [
  { name: 'Client One', image: '/projects/client-one.jpg', accent: '#0e7490' },
  { name: 'E-commerce Store', image: '/projects/ecommerce-project.png', accent: '#f59e0b' },
  // ... add more projects
]
```

## Tips:

- Use **tall screenshots** (mobile/portrait view) for best results
- Keep file sizes reasonable (compress if needed)
- Recommended dimensions: around 400-600px wide
- Supported formats: JPG, PNG, WebP

Until you add screenshots, placeholder designs will be shown with the accent colors you specify!
